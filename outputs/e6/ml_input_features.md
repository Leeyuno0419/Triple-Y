# E6 학습 예측(`ml`) 입력값 표

강사 피드백 3번(예측 모델 입력 항목 표)용 정리. 값의 정의는 `src/predict/ml_forecast.py`의 `feature_names`·`compute_features`를 따른다.

## 한 줄 요약

- 셀 하나의 **최근 30초 밀도 기록**에서 **14개 입력값**을 뽑는다.
- 모델(Ridge 회귀)은 **60초 뒤 밀도 − 지금 밀도**(변화량)를 맞힌다.
- 예측 밀도 = 지금 밀도 + 모델이 맞힌 변화량. 0보다 작으면 0으로 둔다.
- 모든 셀이 같은 모델 하나를 쓴다. 입력값은 밀도 기록뿐이고 속도(vx, vy)는 쓰지 않는다.

## 입력값 14개

밀도의 단위는 명/㎡, 시간의 단위는 초다. "지금"은 예측하는 시각 t의 밀도다.

| 번호 | 이름 | 뜻 | 단위 | 부호 읽는 법 |
|---|---|---|---|---|
| 1 | `cur` | 지금 밀도 | 명/㎡ | |
| 2~10 | `diff_1s` ~ `diff_9s` | 지금 밀도 − k초 전 밀도 (k = 1~9, 9개) | 명/㎡ | 양수면 최근 k초 사이에 올랐다 |
| 11 | `slope_short` | 최근 10초에 최소제곱 직선을 맞춘 기울기 | 명/㎡/초 | 양수면 오르는 중 |
| 12 | `slope_full` | 30초 전체에 최소제곱 직선을 맞춘 기울기 | 명/㎡/초 | 양수면 오르는 중 |
| 13 | `mean_minus_cur` | 30초 평균 − 지금 밀도 | 명/㎡ | 양수면 지금이 평균보다 낮다 |
| 14 | `std_full` | 30초 동안 밀도의 표준편차(흔들림) | 명/㎡ | 클수록 최근 변동이 크다 |

## 설정 값

| 항목 | 값 | 출처 |
|---|---|---|
| 입력 기간 `history_s` | 30초 | `src/predict/config.py` |
| 예측 시점 `horizon_s` | 60초 | `src/predict/config.py` |
| 직접 쓰는 최근 값 개수 `n_lags` | 10 (지금 + 1~9초 전) | `outputs/e6/E04_039_e6.json` |
| 입력값 개수 | `n_lags + 4` = 14 | `compute_features` |
| 모델 | Ridge, `alpha` = 100000, 합성 데이터 24개 기록으로 학습 | `outputs/e6/E04_039_e6.json` |

## 주의

- 입력은 시각 t까지의 기록뿐이다. t 이후 값은 쓰지 않는다.
- 합성 데이터로만 학습했고 실제 영상으로는 학습하지 않았다. 성능과 한계는 `docs/proposal-detail.md` 7.2.7을 따른다.
- `n_lags`를 바꾸면 입력값 개수와 `diff_*s` 항목 수가 함께 바뀐다. 이 표는 `n_lags` = 10 기준이다.
