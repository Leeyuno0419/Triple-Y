## 요약

- **목표**: 상황실이 흐름을 보고 위험을 미리 알 수 있게 한다.
- **구조**: 인원 모듈과 흐름 모듈의 셀 출력이 시계열 예측 모델(`src/predict/`)의 입력이 된다. 시계열 모델은 T초 뒤 셀 측정값을 예측한다.
- **흐름 모듈에서 학습하는 것**: 광학 흐름 모델의 추가 학습이다. 사전학습 RAFT를 군중 영상에 맞춘다.
    - 정답 흐름이 없으므로 비지도 방식(광도 손실)으로 먼저 학습한다.
    - 결과에 따라 증류·합성 지도 학습과 비교한다.
- **평가**:
    - 최종 기준은 시계열 예측 오차가 줄어드는지다.
    - 시계열 모델이 준비되기 전에는 두 가지로 임시 판단한다. 노이즈 바닥, 그리고 단순 예측 기준선의 오차다.
- **대비책**: G1(11-13)까지 효과가 없으면 사전학습 모델로 고정한다. 파이프라인은 처음부터 사전학습 모델로 끝까지 돌게 만든다.
- **핵심 주의점**: 예측 정답이 흐름에서 나온 값(불안정 지표)이면 순환이 생긴다. 흐름 모델을 바꾸면 입력과 정답이 함께 바뀐다. 그래서 비교 실험의 정답은 흐름과 독립인 값(밀도)이나 고정된 기준 추정기로 계산한다 (2.3).

## 1. 결정 경위

### 1.1 출발점

- 기존 계획은 규칙 기반이다. Farneback 흐름 → 셀 속도 분산 → 군중 압력 P = ρ × Var(v), 기준 0.02/s²이다 (`proposal-detail.md` 3.4).
- 조사 결과 기존 계획에 세 가지 문제가 있다 (난류 조사 요약, 5.4).
    - 0.02/s²는 그대로 옮겨 쓸 수 없다. 원 저자가 "보정해야 한다"고 썼다 [R2].
    - 계획의 `Var_c(v)`는 셀 안 공간 분산이다. 원 정의는 시간 분산이다 [R1].
    - 흐름 잡음이 분산에 그대로 더해진다. 성분당 0.1m/s 잡음이면 밀도 5명/㎡에서 P ≈ 0.1/s²다. 기준의 5배다.
- 난류를 직접 판정하는 공개 가중치 모델은 없다 (모델 조사 요약, 4장).

### 1.2 검토한 아이디어와 결정

| 아이디어 | 검토 | 결정 |
|---|---|---|
| 직접 학습 vs 사전학습 모델 추가 학습 | 처음부터 학습하는 것은 데이터와 일정상 어렵다 | 사전학습 광학 흐름 모델을 추가 학습한다 `[토론]` |
| 학습 데이터가 꼭 영상이어야 하나 | 학습 대상에 따라 다르다. 흐름 모델은 영상이 필요하다. 시계열 모델은 시뮬레이션 셀 시계열로도 학습할 수 있다 | 흐름 학습은 영상, 시계열 보강은 시뮬레이션도 쓴다 `[토론]` |
| 많은 인파와 움직임이 꼭 보여야 하나 | 난류형 움직임은 4~6명/㎡ 이상에서 보고된다 [R4]. 비지도 흐름 학습은 저밀도 영상도 쓸 수 있다. 다만 목표 장면(고밀도)과 비슷할수록 좋다 (가정) | 고밀도 영상을 우선하되 저밀도도 학습에 섞는다 (가정) |
| 인도 CCTV 부족 → AI 가공·증강 | 증강은 겉모습(밝기, 압축, 크기)만 늘린다. 없던 움직임은 못 만든다. 생성 AI 영상의 움직임은 물리적으로 맞는다는 보장이 없다 | 증강은 비지도 학습의 다양화에만 쓴다. 생성 AI 영상은 정답·평가에 쓰지 않는다 |
| GPU 서버에서 학습 | 가능하다. 데이터 이용 조건과 원본 영상 보관 규칙을 확인해야 한다 | GPU 서버에서 학습한다. 조건은 9장 |
| 공부하며 진행 | 사전학습 모델로 끝까지 도는 파이프라인을 먼저 만들면, 그 위에서 단계별로 배울 수 있다 | 7장 학습 순서를 따른다 |

## 2. 모듈 구조와 경계

### 2.1 데이터 흐름

```
영상 프레임
  ├─ src/counting (이유노)  P2PNet + 호모그래피 → 셀 밀도 rho*_c(t)
  └─ src/flow (조영준)      광학 흐름 (사전학습 또는 추가 학습 RAFT)
                            → 셀 평균 속도 V_c(t), 불안정 S_c(t), 압력 P_c(t), 신뢰도 Q_c(t)
                                   ↓ timeline.json (셀·구역 집계값만)
src/predict (나예린)  시계열 모델 입력: rho*_c, V_c, S_c, P_c, 경계 유입 ...
                      출력: T초 뒤 셀 밀도·불안정 지표 (T = 60초, 가정)
```

- 흐름장(픽셀 단위)은 메모리 안에서만 쓰고 셀 통계로 바로 줄인다. 파일로 저장하지 않는다 (CLAUDE.md 개인정보 규칙).
- 지표 정의는 난류 조사 6.4의 후보 세트를 따른다 `[토론]`.
    - `S_c(t) = max(<|V_c − U_c|²>_T − Var_noise_c, 0)`: 시간 분산에서 잡음 바닥을 뺀 값이다.
    - `U_c`는 최근 T초 이동 평균이다 (가정: T = 30초).

### 2.2 `timeline.json` 흐름 필드 후보 `[토론]`

| 필드 | 뜻 | 단위 |
|---|---|---|
| `flow_vx`, `flow_vy` | 셀 평균 지면 속도 `V_c` | m/s |
| `flow_instability` | 불안정 `S_c` | m²/s² |
| `flow_pressure` | 압력 `P_c = rho*_c × S_c` | 1/s² |
| `flow_counterflow` | 역방향 흐름 비율 `B_c` | 0~1 |
| `flow_quality` | 신뢰도 `Q_c` (유효 픽셀 수 등) | 개 |
| `flow_estimator` | 사용한 흐름 추정기 이름·버전 | 문자열 |

- 필드 이름과 주기(1Hz, 가정)는 나예린 님과 함께 정한다.
- `flow_estimator`를 넣는 이유: 사전학습과 추가 학습 결과를 같은 형식으로 저장하고 비교하기 위해서다.

### 2.3 순환 문제와 정답 고정

- 시계열 모델의 정답은 "T초 뒤 측정값"이다. 자기 지도라 라벨 작업이 없다.
- 문제: 정답에 `S_c`·`P_c`를 쓰면 정답도 흐름 모델이 만든다. 흐름 모델을 바꾸면 입력과 정답이 함께 바뀐다. 그러면 예측 오차의 변화가 흐름이 좋아져서인지 정답이 쉬워져서인지 구분할 수 없다.
- 대응 (가정) `[토론]`:
    - 주 정답은 T초 뒤 셀 밀도 `rho*_c(t+T)`다. 밀도는 흐름과 독립이다.
    - 불안정 지표를 정답으로 쓸 때는 고정된 기준 추정기(사전학습 RAFT 또는 Farneback)로 계산한 값을 쓴다.
    - 흐름 추정기만 바꾸고 나머지(셀, 창, 시계열 모델, 시드)는 고정해 비교한다.

## 4. 흐름 모델 추가 학습

### 4.1 출발 모델

- torchvision RAFT(`raft_small` 또는 `raft_large`)에서 시작한다 [M1][M2].
    - 이유: BSD-3 라이선스이고 `torchvision` 하나로 설치된다.
    - 입력 높이·너비는 8의 배수여야 한다 [M2].
- Farneback과 DIS는 학습하지 않는 비교 기준선으로 둔다 (`proposal-detail.md` 7.2.3, E4).

### 4.2 학습 방식 비교

| 방식 | 원리 | 필요한 것 | 장점 | 단점 | 순서 |
|---|---|---|---|---|---|
| 비지도 추가 학습 | 프레임 1을 예측 흐름으로 비틀어(warp) 프레임 2와 맞춘다. 그 오차(광도 손실)와 평활 손실로 학습한다 | 영상만 | 정답이 필요 없다. 국내 화각 영상을 그대로 쓴다 | 반복 무늬·가림·정지 배경에 약하다. 손실이 줄어도 흐름이 정확해졌다는 보장은 약하다 | 1순위 |
| 증류 (교사 → 학생) | 큰 모델(예: SEA-RAFT [M7])의 흐름을 정답 삼아 작은 모델을 학습한다 | 영상 + 교사 모델 | 학습이 안정적이다. 속도를 얻는다 | 교사의 오류를 그대로 배운다. 교사보다 정확해지기 어렵다 | 비지도 결과를 보고 결정 |
| 합성 지도 학습 | 정답 흐름이 있는 합성 군중 영상으로 학습한다 | TUB CrowdFlow [M20] 또는 직접 렌더링 | 정답이 정확하다 | 데이터 확보가 불확실하다. 렌더링 환경 구축에 며칠이 든다 | 여유 시 |

- 비지도 학습의 대표 연구 (방법 참고용):
    - UFlow (ECCV 2020): 광도 손실, 가려짐 처리, 평활 정규화의 선택지를 체계적으로 비교했다 [P1]. 공식 코드는 TensorFlow다.
    - SMURF (CVPR 2021): RAFT 구조에 비지도 시퀀스 손실, 자기 지도 손실, 화면 밖 움직임 처리를 더했다 [P2]. UFlow 대비 36~40% 개선을 보고했다. 공식 코드는 JAX다.
    - ARFlow (CVPR 2020): 증강한 입력의 예측을 변환해 자기 지도 신호로 쓴다 [P3]. PyTorch 코드가 있다. 코드 라이선스는 (확인 필요)다.
- 위 연구는 군중 영상으로 평가되지 않았다. 군중 영상에서의 효과는 우리가 직접 재야 한다.

### 4.3 비지도 학습의 군중 영상 대응 (가정)

| 문제 | 대응 |
|---|---|
| 정지 배경이 화면 대부분이다 → 0 흐름만 배운다 | 손실을 보행 가능 영역·군중 영역 마스크 안에서만 계산한다 |
| 밝기 변화·압축 잡음 | 밝기 변화에 강한 손실(census 등)을 쓴다. UFlow가 비교한 손실 중에서 고른다 [P1] (확인 필요) |
| 가림 | 앞뒤 흐름 일치 검사로 가려진 픽셀을 손실에서 뺀다 [P1] |
| 사전학습 성능을 잃음 (망각) | 학습률을 작게 두고 짧게 학습한다. 사전학습 대비 노이즈 바닥이 나빠지면 멈춘다 |
| 작은 이동량 (정체 시 1px 미만) | 프레임 간격을 늘려 학습·추론한다 (난류 조사 5.1) |

### 4.4 실험 기록

- 랜덤 시드를 고정한다.
- 학습 설정(데이터 목록, 해상도, 프레임 간격, 손실 가중치, 학습률, 반복 수)과 결과를 `outputs/`에 표로 남긴다.
- 가중치는 GPU 서버에만 두고 git에 올리지 않는다.

## 5. 평가

### 5.1 단계별 기준

| 단계 | 시점 | 지표 | 정답 필요 | 의미 |
|---|---|---|---|---|
| 중간 1 | 학습 직후 | 노이즈 바닥: 정지 배경 셀의 속도 분산 `Var_noise_c` | 없음 | 잡음이 줄었는가 |
| 중간 2 | 학습 직후 | 단순 예측 기준선의 T초 뒤 오차 (현재값 유지, 흐름 외삽) | 자기 지도 | 흐름이 예측에 쓸모 있는가 |
| 보조 | 가능하면 | Jülich 궤적 대비 셀 속도 오차 [R21] | 궤적 | 속도가 정확해졌는가 |
| 최종 | 시계열 모델 준비 후 | 나예린 님 시계열 모델의 T초 뒤 예측 오차 | 자기 지도 | 목표 직결 |

- 모든 비교는 사전학습 RAFT, Farneback, DIS와 같은 셀·같은 창·같은 영상에서 한다.
- 정답은 2.3의 고정 규칙을 따른다.
- 흐름 외삽 기준선은 `proposal-detail.md` 3.4(4)의 방식을 셀 단위로 줄여 쓴다 (가정).

### 5.2 G1(11-13) 판정 기준 (가정) `[토론]`

- 채택 조건: 아래 둘을 모두 만족한다.
    - 노이즈 바닥이 사전학습 RAFT보다 낮다.
    - 기준선 예측 오차가 사전학습 RAFT보다 나쁘지 않다.
- 개선 폭의 수치 기준은 팀이 정한다.
- 조건을 만족하지 못하면 사전학습 모델 중 가장 나은 것으로 고정한다. 남은 시간은 지표 검증(난류 조사 6.5의 V1·V2·V5)과 통합에 쓴다.

## 7. 학습 순서 (공부 경로)

- 원칙: 파이프라인 단계마다 "직접 돌려 보고 숫자를 확인한다". 이론은 그 단계에 필요한 만큼만 읽는다.

| 순서 | 공부할 것 | 읽을 자료 | 직접 해 볼 것 |
|---|---|---|---|
| 1 | 광학 흐름이 무엇이고 무엇을 못 하는가 (조리개 문제, 가림) | 난류 조사 5.1, OpenCV Farneback·DIS 문서 | 영상 두 프레임의 흐름을 색으로 그려 본다 |
| 2 | 픽셀 이동량 → 지면 속도 (호모그래피) | `proposal-detail.md` 3.4(1)(2), 난류 조사 5.2 | 바닥 4점으로 H를 구하고 셀 속도를 m/s로 바꾼다 |
| 3 | 셀 통계와 잡음 바닥 | 난류 조사 5.3·5.4 | 정지 구간에서 `Var_noise_c`를 잰다 |
| 4 | 군중 압력의 원 정의 | Helbing 2007 [R1], Johansson 2008 [R2] | 공간 분산과 시간 분산을 같은 영상에서 비교한다 |
| 5 | RAFT 구조와 사용법 | RAFT 논문 [M1], torchvision 문서 [M2] | 사전학습 RAFT로 1~3을 반복한다 |
| 6 | 비지도 흐름 학습 | UFlow [P1], SMURF [P2] | 광도 손실을 직접 계산해 본 뒤 추가 학습한다 |
| 7 | 군중 동역학의 최근 결과 | Gu 외 2025 [R4] | 팜플로나 영상으로 사슬을 돌려 본다 (여유 시) |
